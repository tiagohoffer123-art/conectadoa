# ConectaDoa

Sistema de gestão de doações para ONG.
Projeto Integrador Extensionista · ADS.

## Requisitos

- Git
- Node.js (LTS)

## Como rodar

1. Clone o repositório e entre na pasta:
   ```
   git clone https://github.com/SEU-USUARIO/conectadoa.git
   cd conectadoa
   ```
2. Instale as dependências: `npm install`
3. Copie `.env.example` para `.env`
4. Terminal 1, inicie a API: `npm run api`
5. Terminal 2, inicie o frontend: `npm run dev`
6. Abra http://localhost:5173
